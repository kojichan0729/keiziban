# RSS掲示板（ニュース速報＋風）

RSSフィードの記事が自動でスレッド化される、2ch/5ch風の匿名掲示板です。

## 特徴

- 板（カテゴリ）ごとに異なるRSSフィードを割り当て（総合ニュース、IT、スポーツなど）
- 10分ごとに自動でRSSを再取得し、新着記事を自動スレ立て
- 匿名でレス（コメント）を投稿可能（デフォルト名「名無しさん」）
- 「新着順」「レス数順」「勢い順」で並び替え
- 全板横断の「勢いランキング」トップページ
- データは `data/board.json` にファイル保存（サーバー再起動しても消えません）

## セットアップ

```bash
npm install
npm start
```

起動したら `http://localhost:3000` をブラウザで開いてください。

## 新機能

### ロゴ・ファビコン

- `public/logo.png` を置くとヘッダーのタイトル部分に表示されます（サイト名の文字入りロゴを想定）
- `public/favicon.png` を置くとブラウザタブのファビコンになります
- どちらも未配置ならエラーにはならず、ロゴは代替テキスト「こっちゃんねる」、ファビコンはブラウザ標準のものが表示されます

```bash
cp /path/to/logo.png rss-bbs/public/logo.png
cp /path/to/favicon.png rss-bbs/public/favicon.png
```

### 新規スレッド作成

各板の一覧画面上部にある「＋ 新規スレッド作成」ボタンから、自分でスレッドを立てられます（タイトル必須、本文は任意）。RSSから自動生成されたスレッドと同じ扱いで、レス・いいね・アンカーも通常通り使えます。

### NEWバッジ（既読管理つき）

作成から6時間以内のスレッドには一覧に赤い「NEW」バッジが付きます。バッジが**合計3秒間、実際に画面に表示された状態**が続くと自動でフェードアウトし、その既読状態はブラウザに保存されます。ページを閉じて開き直したり、板を切り替えて戻ってきたりしても、一度読んだスレッドのNEWバッジは再表示されません（ブラウザタブが非アクティブな間はカウントされません）。しきい値を変えたい場合は `server.js` の `NEW_THREAD_THRESHOLD_MS` を編集してください。

### ローディング表示

一覧やスレッド詳細の読み込み中はスケルトン（骨組み）表示、初回アクセス時やボタン送信中はくるくる回るスピナーが出るようになっています。

### `>>N` アンカー（レス参照）

- レス本文に `>>1` のように書くと、自動でクリック可能なリンクになります
- リンクをクリックするとそのレスまでジャンプ＆ハイライト
- リンクにマウスを乗せると内容がポップアップでプレビューされます
- レス番号（例: `2`）をクリックすると、返信フォームに `>>2 ` が自動入力されます

### 背景画像

`public/bg.jpg` という名前で好きな画像を置くと、自動で背景に反映されます。

```bash
cp /path/to/your-image.jpg rss-bbs/public/bg.jpg
```

- 画像は画面全体を覆うように自動でリサイズ表示されます（`background-size: cover`）
- jpg以外（png等）を使いたい場合は `public/style.css` 内の
  ```css
  background-image: url('bg.jpg');
  ```
  を `url('bg.png')` などお好きなファイル名に書き換えてください
- 画像が無い場合は薄いグレーの背景色にフォールバックします（エラーにはなりません）
- 背景は不透明度32%で薄く表示され、スクロールすると画面より遅い速度でゆっくり下に動くパララックス効果が付いています。不透明度を変えたい場合は `public/style.css` の `.bg-layer` の `opacity`、動く速さを変えたい場合は `public/app.js` の `PARALLAX_FACTOR`（0〜1、大きいほど速い）を編集してください

## 広告枠（将来の外部広告用）

将来、外部広告（AdSenseなどの埋め込みタグ）を表示できるように、3つの広告枠を用意してあります。

- `top-banner`: ホーム画面・各板一覧の上部
- `sidebar`: ホーム画面のお知らせボックスの下
- `thread-bottom`: スレッド詳細ページの、投稿一覧と返信フォームの間

管理者ログイン後、フッターの「広告管理」から各枠のON/OFFと埋め込みHTMLを設定できます。空欄・OFFの間は何も表示されないので、今の状態では広告は一切出ません。`<script>`タグを含む広告コードもそのまま実行されるように挿入する仕組みになっています。

設定は `data/ads.json` に保存されます（`.gitignore`済み・サーバー環境ごとに個別設定）。

## フォロー機能（一般ユーザー登録）

管理者ログインとは別に、誰でもアカウント登録してログインできます（ヘッダー右上の「ログイン / 新規登録」）。ログインすると：

- 投稿時の名前が自分のユーザー名で固定されます（匿名の「名無しさん」投稿も、ログインしなければ引き続き可能です）
- スレッド詳細ページの「☆ このスレをフォロー」から、スレッドをフォローできます
- 他の登録ユーザーの投稿名の横に出る「＋ フォロー」から、その人をフォローできます（自分自身はフォロー不可）
- ヘッダーの「◯◯さん」→「マイページ」で、フォロー中のスレッド一覧・ユーザー一覧（フォロワー数付き）を確認できます

ユーザーデータは `data/users.json` に保存されます（パスワードはハッシュ化して保存、`.gitignore`済み）。管理者アカウントとは完全に別の仕組みです。

## 管理者機能

指定したメールアドレスとパスワードでログインすると、管理者として次のことができます。

- 「サイトのお知らせ」板への投稿（管理者以外はこの板に投稿できません）
- 各投稿への処分（注意・警告・厳重注意・BAN）— フッターの「管理者ログイン」からログインすると、各レスの下にモデレーション用のプルダウンが表示されます。BANにするとその投稿の本文は「表示する」ボタンを押すまで隠れます
- 管理者としてコメントすると、名前の横に緑の「運営」バッジが付きます

ログインはフッター右下の「管理者ログイン」から行います。ログイン情報（メールアドレス・パスワードのハッシュ）は `server.js` の `ADMIN_EMAIL` / `ADMIN_PASSWORD_SALT` / `ADMIN_PASSWORD_HASH` に設定されています。パスワードそのものはどこにも平文で保存されていません。

パスワードを変更したい場合は、以下のスクリプトで新しいソルトとハッシュを生成し、`server.js` の該当箇所を置き換えてください。

```bash
node -e "
const crypto = require('crypto');
const salt = crypto.randomBytes(16).toString('hex');
const hash = crypto.scryptSync('新しいパスワード', salt, 64).toString('hex');
console.log('ADMIN_PASSWORD_SALT =', salt);
console.log('ADMIN_PASSWORD_HASH =', hash);
"
```

管理者セッションはサーバーのメモリ上で管理しているため、サーバーを再起動するとログアウトされます（7日間の有効期限あり）。

## 板の構成

ナビゲーションは5つのグループに分かれています。

- **ニュース**（無印・RSS自動スレ立て、常にナビに表示）: 総合ニュース速報／IT・ガジェット／スポーツ／ネット・話題／ガジェット速報
- **技術**（ボタンを押すと画面幅いっぱいの一覧が開きます）: C++／Python／Web開発／AI・機械学習（QiitaのRSSあり）、キーボード・マウス沼／Linux・macOS・Windows／サーバー・ネットワーク／セキュリティ・ハッキング学習／プログラミング質問総合
- **雑談・相談**: 人生・進路相談／恋愛・人間関係相談／おすすめ募集・質問総合／コラボ・メンバー募集／バイト・仕事相談／アンケート・意見募集／AA(アスキーアート)
- **学問・雑学**: 数学総合／数学オリンピック・難問／パズル・論理クイズ／物理・天文学／化学・生物／哲学・心理学／歴史・地理
- **サイト運営**: バグ報告・要望・機能提案／サイトのお知らせ／通報・お問い合わせ

「技術」「雑談・相談」「学問・雑学」「サイト運営」はナビ上ではボタン表示になっていて、クリックすると画面幅いっぱいのパネルに板の一覧が展開されます（もう一度押す、リンクをクリックする、パネルの外側をクリックすると閉じます）。

RSSが無い板は自動スレ立てはされず、「＋ 新規スレッド作成」からユーザーがスレを立てて使う板になります。

### お知らせボックス

ホーム（全板勢いランキング）画面の右側に、「サイトのお知らせ」板の最新スレッドを一覧表示する専用ボックスが表示されます。運営からのお知らせは「サイトのお知らせ」板でスレッドを立てれば、自動的にこのボックスにも反映されます。

## 板（フィード）のカスタマイズ

`server.js` の先頭にある `BOARDS` 配列を編集すると、板の名前やRSSフィードのURLを自由に変更・追加できます。`category: 'other'` を付けた板は、ナビゲーションで「その他」として分けて表示されます（現在はC++・Python・Web開発をQiitaのタグ別フィードで用意しています）。

```js
const BOARDS = [
  { id: 'general', name: '総合ニュース速報', rss: 'https://example.com/rss.xml', category: 'news' },
  { id: 'rust', name: 'Rust', rss: 'https://qiita.com/tags/rust/feed.atom', category: 'other' },
  // ここに追加していく
];
```

## 仕組みメモ

- `server.js`: Express製サーバー。RSS取得（rss-parser）、掲示板API、静的ファイル配信を担当
- `public/`: バニラJSのSPAフロントエンド（2ch風デザイン）
- `data/board.json`: スレッドとレスの永続化データ

## 注意

- RSSの取得はサーバー起動時と10分おきの自動更新のみ行われます。すぐに反映したい場合はサーバーを再起動してください。
- フィードによっては本文（summary）が短い/取れないことがあります。
